# Restaurant — Digital Tab App

> Interactive app prototype for restaurants, featuring QR-linked digital tabs, live ordering and a loyalty club.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Restaurants & food service

Interactive app prototype for restaurants, featuring QR-linked digital tabs, live ordering and a loyalty club.

**Highlights**

- Digital tab linked by QR code or manual number entry
- Live order list with running total
- Loyalty club and weekly featured menu

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
